გაიცანი, აპლიკაციად
სწრაფი წვდომა მთავარი ეკრანიდან — ბრაუზერის გარეშე, ისე როგორც ჩვეულებრივი აპლიკაცია
  1. გახსენით საიტი Chrome-ში
  2. დააჭირეთ ზედა მარჯვენა კუთხეში ⋮ ღილაკს
  3. აირჩიეთ „აპის ინსტალაცია" ან „მთავარ ეკრანზე დამატება"
  4. დაადასტურეთ — მზადაა! 🎉
  1. გახსენით საიტი Safari-ში (სხვა ბრაუზერში არ მუშაობს)
  2. დააჭირეთ გაზიარების ღილაკს ⎋ ქვედა ზოლში
  3. ჩამოსქროლეთ და აირჩიეთ „მთავარ ეკრანზე დამატება" (Add to Home Screen)
  4. დააჭირეთ „დამატება" ზედა მარჯვენა კუთხეში — მზადაა! 🎉
  1. გახსენით საიტი Chrome-ში ან Edge-ში
  2. მისამართის ველის ბოლოში იხილავთ ⊕ ხატულას — დააჭირეთ მას
  3. აირჩიეთ „Install"
  4. გაიხსნება ცალკე ფანჯარაში, საკუთარი ხატულით — მზადაა! 🎉
